# R Dialer v1.0.0 — First Release

First public-ready Phase 1 build of R Dialer.

### Included
* Basic dialer with clean modern white/light UI
* Real phone calling via Android Telecom framework
* Incoming call handling with lockscreen awareness
* Outgoing call handling with live DTMF tone generation
* Contacts integration with fast search and contact avatars
* Call history with incoming/outgoing/missed status and duration
* 3-tier contact avatar system (Photo -> First Letter Initial -> Unknown placeholder)
* Runtime Android permissions (Contacts, Call Log, Phone state, Notifications)
* Android Telecom `InCallService` integration
* Default phone app support via Android `RoleManager`
* Multitasking-friendly call experience (heads-up notifications while using other apps)

### Future Roadmap
Future releases may introduce:
* Caller ID & Directory Lookup
* Spam detection and blocking
* Advanced call management
* Additional personalization and customization
